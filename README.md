# scoremesh

Score identifiers and mesh tokens for idempotent workflows.

**Site:** https://theworker02.github.io/scoremesh/

## Install / run

```bash
git clone https://github.com/theworker02/scoremesh.git
cd scoremesh
node src/cli.js
node --test
```
